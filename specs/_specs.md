# Project Chimera: Meta Specification

## Vision

Chimera is an agentic infrastructure designed to autonomously generate, curate, and publish influencer-style content across social platforms. It leverages AI agents to detect trends, produce media, and interact with networks like OpenClaw.

## Constraints

- Agents must comply with platform policies (no harmful or misleading content).
- Agents must operate within ethical guidelines (no impersonation, respect privacy, no pornographic or violent content).
- Agents operate within defined resource limits (CPU, memory, API quotas).
- All data storage must be GDPR-compliant.
- Integration limited to approved APIs (Twitter, TikTok, OpenClaw).
